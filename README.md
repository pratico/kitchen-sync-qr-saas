# kitchen-sync-qr-saas
Kitchen-Sync QR SaaS — Sistema per ristoranti e pizzerie che permette ai clienti di ordinare dal tavolo tramite QR code e invia istantaneamente la comanda sullo schermo della cucina con avviso sonoro e sintesi vocale, includendo un modulo anti-spreco per promuovere offerte lampo sulle rimanenze.
